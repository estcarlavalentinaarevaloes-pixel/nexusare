# nexusare

Proyecto de videojuego NEXUS.

## Objetivo del repositorio

Documentar el proyecto NEXUS y practicar el uso de GitHub para organizar y registrar cambios.

## Práctica de Pull Requests

El proceso de trabajo consiste en:

1. Crear una rama para realizar una modificación.
2. Modificar la documentación del proyecto.
3. Registrar el cambio mediante un commit.
4. Crear un Pull Request hacia la rama principal.
5. Revisar los cambios antes de incorporarlos.
6. Fusionar el Pull Request y comprobar el resultado.
